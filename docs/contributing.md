# Contributing to Agent Kernel

Please see the [CONTRIBUTING.md](https://github.com/agent-kernel/agent-kernel/blob/main/CONTRIBUTING.md) file in the repository root for full contribution guidelines.

The guide covers:

- **Prerequisites** -- Python 3.11+, uv package manager
- **Development Setup** -- Clone, virtual environment, dependency installation
- **Quality Checks** -- Linting, formatting, type checking, testing
- **Code Style** -- Ruff formatting, Google-style docstrings, type hints
- **Pull Request Process** -- Small focused PRs, descriptive commits, CI requirements
- **Architecture Overview** -- Schema contracts, tool broker, trace system

# Getting Started

Welcome to Agent Kernel! This section walks you through installation, creating your first agent engine, and producing a complete `DecisionTrace` -- all in under five minutes.

## What You Will Learn

1. **Install** Agent Kernel with `pip install agentkernel`
2. **Create** a stub agent engine (no API keys required)
3. **Execute** a plan through the deterministic executor
4. **Inspect** the resulting `DecisionTrace` -- the immutable audit record

## Ready?

Head to the [Quickstart](quickstart.md) to get your first agent running.
